# AA Hotels Website Demo

A polished static website demo for **AA Hotels**, created to present a premium hotel booking and enquiry experience.

## Features

- Luxury hotel homepage with strong first-screen branding
- Room showcase cards with pricing and amenities
- Interactive amenities tabs
- Events, banquets, and private dining sections
- Guest review section
- Booking and enquiry forms
- Fully responsive layout for desktop and mobile

## Preview

Open `index.html` in a browser, or publish this repository with GitHub Pages.

## GitHub Pages

After pushing to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Set source to **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your live demo URL will be available from GitHub Pages after deployment.
